My vision of AI

Four ideas guide what I build.

Right-size the model to the step

Most steps in a real AI system are small: route this, check that, classify the other. A compact model can do them locally, cheaply and privately. Frontier models should be kept for the steps that need them.

In practice: Erawan 1, a 1.7B model.

Workflows first, autonomy when it's earned

Agents are powerful, but predictable structure usually wins. Start with the simplest pattern that works, and give the model control only when the task can't be written down in advance.

In practice: Agentic Workflows, six patterns from fixed pipelines to autonomous agents.

Open and portable, no lock-in

Models and tools should work across providers and on your own hardware. The same code should run on a hosted API or on a model on your laptop.

In practice: Apache 2.0 weights, and workflows that run on Claude, OpenAI or a local model.

Claims you can check

AI results should come with sample sizes and reproducible evaluations, not just headline numbers. If a result can't be checked, it shouldn't be claimed.

In practice: Erawan's early results are published with their sample sizes, and full benchmarks come next.
